# 8. Test Deliverables

* Software Test Plan (this document - `STP.pdf`).
* Automated Test Scripts (Unit, API, Performance, Security, E2E, UAT): `backend/tests`, the frontend unit tests, `qa/newman`, `qa/k6`, `qa/zap`, `qa/e2e` and `qa/uat`.
* Test Data Seed Scripts: `backend/app/seed`.
* Test Execution Logs and Coverage Reports: the raw tool output in `qa/reports/`, and the final unit, system validation, code coverage and branch coverage reports in `docs/reports/`.
* Defect Reports and Triage Summaries: `docs/qa/SECURITY-TRIAGE.md` and the defect log in `docs/uat/UAT-RESULTS.md`.
* Final Test Execution & Acceptance Report: `qa/reports/TEST-EXECUTION-REPORT.md`, with the acceptance results and sign-off in `docs/uat/`.
