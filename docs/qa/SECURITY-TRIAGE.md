## How to add a finding
1. Fix it if you can, and add a regression test (preferably in `backend/tests/admin_metrics/test_security.py`).
2. If it cannot be fixed, add a row above explaining why the risk is acceptable, then (only then) silence it narrowly: a single rule ID in `qa/zap/rules.conf` or a single advisory ID in `qa/run.py`. Never disable a whole tool.
